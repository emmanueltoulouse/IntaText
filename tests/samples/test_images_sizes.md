# Test des tailles d'images

Ce fichier permet de tester l'insertion d'images de différentes tailles dans l'éditeur WYSIWYG.

## Instructions de test :

1. Passez en mode WYSIWYG
2. Cliquez sur le bouton image dans la barre d'outils
3. Testez avec les différentes images disponibles :

### Images disponibles pour test :

- **test-image.png** : Petite image (48x48 pixels) - devrait être agrandie à ~80x80px
- **test-image-large.png** : Grande image (1024x1024 pixels) - devrait être réduite à 400x400px  
- **test.png** : Grande image (1024x1024 pixels) - devrait être réduite à 400x400px

### Résultat attendu :

Chaque image devrait maintenant avoir une taille appropriée et différente selon sa taille originale, fini les images toutes identiques et très petites !
