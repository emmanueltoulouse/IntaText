# Test d'indentation - Listes et structures

## Listes numérotées simples

1. Premier élément de la liste
2. Deuxième élément de la liste
3. Troisième élément de la liste
4. Quatrième élément avec plus de contenu pour tester l'indentation sur plusieurs lignes

## Listes à puces simples

- Premier élément à puce
- Deuxième élément à puce
- Troisième élément à puce
- Élément avec beaucoup de contenu qui s'étend sur plusieurs lignes pour tester l'indentation

## Listes imbriquées

1. Élément de niveau 1
   - Sous-élément A
   - Sous-élément B
   - Sous-élément C
2. Deuxième élément de niveau 1
   1. Sous-numérotation A
   2. Sous-numérotation B
3. Troisième élément de niveau 1

## Listes avec contenu mixte

1. Élément avec du **texte formaté**
   - Sous-élément avec `code inline`
   - Sous-élément avec [lien](http://example.com)

2. Élément avec bloc de code:
   ```python
   def test():
       return True
   ```

3. Élément final

## Listes avec séparateurs

- Groupe A:
  - Élément A1
  - Élément A2

- Groupe B:
  - Élément B1
  - Élément B2

## Tâches (checkboxes)

- [ ] Tâche non terminée
- [x] Tâche terminée
- [ ] Autre tâche en attente
- [x] Tâche finie avec **formatage**
